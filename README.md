## Slike

U `slike.json` se slika povezuje sa stranicom preko njenog sluga (naziva `.txt`
fajla bez nastavka). Svaka stavka ima naziv fajla iz `slike/` i obavezni `alt`
opis. Stranica bez stavke ostaje bez slike.
